Install LoudScript

  1. Download the LoudScript DMG using the button above.
  2. Open the downloaded DMG and copy LoudScript to your Applications folder.
  3. Open LoudScript from Applications. macOS verifies the signed and notarized app before launch.
  4. Follow the in-app setup for selected-text and screenshot permissions only if you want those workflows.

LoudScript checks its signed update feed when it opens, so later Mac releases can be installed through the app.

What the Mac app can read

  • Selected text from browsers, email, editors, and other Mac apps.
  • Unselectable on-screen text captured with screenshot OCR.
  • Up to 50 consecutive PDF pages per import, with synchronized document highlighting.
  • Text entered or pasted directly into LoudScript.

Speech stays on your Mac when you use Apple voices or a downloaded Supertonic, Kokoro, or PocketTTS model. Optional AI formatting is separate and can send the text being formatted to the provider you configure.
