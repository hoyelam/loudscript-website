Changelog

New features, improvements, and fixes in every public release.

Version 2026.1.19 Latest

19 August 2026
  • Added native Mac menus and keyboard shortcuts for creating, importing, saving, copying, and controlling reads.
  • Moved read details into a dedicated Overview panel to keep the reading area focused.
  • Improved the main window layout so history, reading, and Overview content adapt to the available width.

Version 2026.1.18

16 August 2026
  • Text formatting now stays off until you choose to enable it.
  • Improved reliability when downloading and loading speech models.
  • Improved handling of unusually large text selections and online responses.

Version 2026.1.17

13 August 2026
  • Added PDF imports with drag and drop and page-range selection.
  • Added an original document view with sentence highlighting that follows playback.
  • Added flexible document reading controls for showing or hiding text and the overview.
  • Improved PDF import reliability and performance for larger documents.
  • Added automatic update checks when LoudScript opens.

Version 2026.1.16

7 August 2026
  • Added sentence-by-sentence navigation, including clicking a sentence to start reading there.
  • Added playback progress with the current sentence and estimated time remaining.
  • Added finer speech-speed control with sliders in the player and Settings.
  • Improved speech start speed and reduced pauses during continuous playback.
